# Texto sugerido para LinkedIn

**Insurance Intelligence | Inteligência Comercial e Gestão Estratégica de Seguros**

Projeto independente e de caráter educacional para explorar aplicações de Business Intelligence, análise de dados e conceitos de Inteligência Artificial no mercado de seguros. A partir de uma base inteiramente fictícia, o protótipo simula indicadores de produção, conversão, desempenho comercial, carteira e renovações.

O objetivo é aprofundar conhecimentos e demonstrar como dados podem apoiar a interpretação de resultados e a tomada de decisão.

**Importante:** projeto pessoal de aprendizagem, sem vínculo institucional, patrocínio ou integração com o Itaú ou qualquer outra instituição financeira. Todos os dados e cenários são fictícios.

Repositório: https://github.com/1mperador027/insurance-intelligence
