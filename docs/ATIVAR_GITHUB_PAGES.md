# Ativar GitHub Pages

1. Abra Settings do repositório.
2. Entre em Pages.
3. Em Build and deployment, selecione **GitHub Actions** como Source.
4. Aguarde a execução do workflow **Deploy Insurance Intelligence to GitHub Pages** em Actions.
5. Quando o deploy terminar com sucesso, acesse: https://1mperador027.github.io/insurance-intelligence/

O workflow publica o conteúdo da branch main. A página atual é uma demonstração resumida e usa dados sintéticos ilustrativos.
