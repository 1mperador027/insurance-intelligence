# Dashboard interativo

Acesse a [versão publicada no GitHub Pages](https://1mperador027.github.io/insurance-intelligence/).

O dashboard oferece filtros funcionais por competência, produto, equipe e unidade. Os KPIs e gráficos são recalculados com base nos registros da base sintética carregada em JSON.

**Materiais:** [baixar a base CSV](https://1mperador027.github.io/insurance-intelligence/data/insurance_intelligence_csv.zip) · [planilha Excel](https://1mperador027.github.io/insurance-intelligence/data/Insurance_Intelligence_Base_Analitica.xlsx) · [relatório PDF](https://1mperador027.github.io/insurance-intelligence/docs/Projeto_Insurance_Intelligence_Portfolio.pdf).

Todos os dados são fictícios. A leitura de insights usa regras determinísticas; não há IA generativa integrada.
