# Dashboard demonstrativo

Acesse a [versão publicada no GitHub Pages](https://1mperador027.github.io/insurance-intelligence/).

A página web é um protótipo estático e resumido, com KPIs e gráficos demonstrativos. Não possui filtros operacionais. Alguns gráficos são ilustrativos; os status de propostas e renovações reproduzem as quantidades da base sintética.
