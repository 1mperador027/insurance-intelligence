# Insurance Intelligence
### Inteligência Comercial e Gestão Estratégica de Seguros

> **Projeto independente, educacional e experimental.** Desenvolvido para aprendizagem e demonstração de conceitos de Business Intelligence, análise de dados e aplicações de IA no mercado de seguros.

O Insurance Intelligence simula uma operação de seguros com dados inteiramente fictícios para explorar indicadores comerciais, desempenho de equipes, conversão de propostas, gestão de apólices e renovações.

## Objetivo
Demonstrar, em um cenário simulado, como dados estruturados e ferramentas analíticas podem apoiar a leitura de desempenho, identificação de tendências e discussão de oportunidades comerciais.

## Demonstração
O protótipo interativo do dashboard será disponibilizado neste repositório em **dashboard/**. Para executá-lo localmente, baixe o arquivo HTML e abra-o em um navegador moderno. A publicação web depende da ativação do GitHub Pages após a disponibilização do dashboard.

## Conteúdo do projeto
- **Dashboard interativo:** filtros por período, produto, equipe e unidade; indicadores, gráficos e tabela gerencial.
- **Base analítica:** planilha com tabelas simuladas.
- **Dados CSV:** dimensões e fatos para estudo e importação no Power BI.
- **Medidas DAX:** exemplos iniciais para análise.
- **Documentação:** arquitetura, definições, premissas e instruções de uso.

## Tecnologias e conceitos explorados
- Excel e CSV para estruturação dos dados;
- Power Query / modelagem dimensional como abordagem de preparação;
- Power BI e DAX como caminho de evolução analítica;
- HTML e JavaScript para o protótipo de dashboard;
- regras determinísticas para gerar comentários demonstrativos sobre indicadores.

**Nota sobre IA:** a leitura inteligente atualmente presente no protótipo é baseada em regras fixas. Não há integração com um modelo de IA generativa nesta versão.

## Premissas e transparência
- Todos os registros, nomes, unidades, equipes, valores e resultados são **fictícios e sintéticos**.
- O projeto não utiliza dados reais de clientes, colaboradores, instituições ou operações.
- Não possui vínculo institucional, patrocínio, endosso ou integração com o Itaú ou qualquer outra instituição financeira.
- Não se conecta a sistemas corporativos, APIs privadas ou bases de dados externas.
- Não representa produtos, processos, metas ou indicadores oficiais de qualquer empresa.
- É um projeto pessoal de aprendizagem, experimentação e desenvolvimento de portfólio.

## Limitações da versão demonstrativa
Esta versão é um protótipo independente. Não inclui arquivo Power BI (.pbix), publicação operacional, autenticação, backend, integração com sistemas externos ou IA generativa. Os indicadores devem ser interpretados apenas dentro do cenário sintético.

## Como começar
1. Consulte a pasta `data/` para conhecer os dados fictícios.
2. Leia `docs/ARQUITETURA_E_MODELO.md` e `docs/DEFINICOES_E_LIMITACOES.md`.
3. Abra o dashboard HTML em um navegador quando o arquivo estiver publicado em `dashboard/`.
4. Use os CSVs como material de estudo para modelagem e exercícios no Power BI.

## Uso responsável
O material é disponibilizado para fins educacionais. Antes de adaptar o projeto para qualquer contexto real, é necessário avaliar qualidade dos dados, privacidade, segurança, governança, autorização e adequação regulatória.
